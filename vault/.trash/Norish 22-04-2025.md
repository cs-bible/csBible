# 🛠️ Norish Docker Redis MISCONF - Solución Rápida

**Fecha:** 22/04/2026  
**Problema:** Redis bloquea escrituras por falta de espacio en disco para snapshots RDB  
**Impacto:** Norish no arranca, Bull Queue falla, tareas programadas colgadas  
**Resultado:** ✅ Arreglado sin pérdida de datos (recetas en PostgreSQL intactas)

## 🎯 Error Clave


```txt
MISCONF Redis is configured to save RDB snapshots, but it's currently unable to persist to disk. Commands that may modify the data set are disabled (stop-writes-on-bgsave-error option).
```
## 🔧 Solución (desde HOST)

## **1. Desbloquear Redis**


```bash user="xerve" host="fenrir" title=desbloquear redis"
docker exec -it norish-redis redis-cli CONFIG SET stop-writes-on-bgsave-error no 
docker exec -it norish-redis redis-cli CONFIG REWRITE
```
## **2. Verificar**

```bash user="xerve" host="fenrir" title=verificar"
docker exec -it norish-redis redis-cli PING  
# Debe responder PONG
```
## **3. Reiniciar servicios**

bash

`docker compose -f docker-compose.yml restart redis docker compose -f docker-compose.yml down && docker compose -f docker-compose.yml up -d`

## **4. Logs para verificar**

docker compose -f docker-compose.yml logs redis docker compose -f docker-compose.yml logs norish

## 💡 Prevención futura

**En `docker-compose.yml` agregar a Redis:**

```docker
redis:   command: redis-server --stop-writes-on-bgsave-error no --save ""  volumes:    - redis_data:/data
```

**Monitoreo espacio disco:**

```bash user="xerve" host="fenrir" title=verificar"
# Script crontab diario #!/bin/bash USED=$(df / | awk 'NR==2 {print $5}' | sed 's/%//') if [ $USED -gt 85 ]; then   docker system prune -f fi
```

## 📋 Notas importantes
- **Recetas seguras** → PostgreSQL (no Redis)
- **Bull Queue** → Solo tareas temporales (sync, parsing)
- **Causa raíz** → Disco lleno impide snapshots RDB
- **Contenedor afectado** → `norish-redis`
