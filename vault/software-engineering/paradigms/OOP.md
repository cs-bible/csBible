# Object-Oriented Programming :LiCuboid:

## Description
Programming paradigm that organizes code around **objects** that combine state (attributes) and behavior (methods).

## The 4 Pillars
- **Encapsulation** → hide internal details, expose interfaces (see [[accessModifiers|access modifiers]])
- **Inheritance** → code reuse between related classes (see [[inheritance|Inheritance in Java]])
- **Polymorphism** → same interface, different behaviors (see [[inheritance#Overwrite-Runtime|Overwriting]])
- **Abstraction** → model only what's relevant to the domain


## Implementation by Language
| Language | Multiple Inheritance | Interfaces | Note |
|---|---|---|---|
| Java | ❌ (single only) | ✅ | Multiple `implements` |
| C++ | ✅ | ✅ (abstract classes) | More complex |
| C# | ❌ | ✅ | Similar to Java |
