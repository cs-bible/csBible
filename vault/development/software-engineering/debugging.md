# Code Debugging :LiBug: 

Debugging allows <mark style="background: #FF5582A6;">identifying and correcting programming errors through controlled software execution</mark>. This task is performed by the debugger or *Debugger*

> [!info] Debugger
> Thanks to the debugger we can see the execution process of a program step by step, observing the values of our methods, variables, and objects

There is another mode that uses breakpoints to control parts of the software independently.
