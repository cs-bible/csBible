# Introduction
[[languages/c/README|C]] is a [[computer-science/compilers/README|compiled]], statically typed language.

It is a low-level language and provides fine-grained control over memory.

It does not have a [[garbage collector]].

It is widely used for systems programming, embedded systems, and operating systems.

This directory focuses on C99. At the bottom of each note, you can find a clarification about modern C for that specific topic.
