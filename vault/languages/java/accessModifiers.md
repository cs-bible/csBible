# Java - Access modifiers :DeJavaOriginal:
Access modifiers in Java control attributes’s and method’s visibility inside a Class.

There are for main levels
`public`: Accessible from every class in every package
`protected`: Accessible inside the same package and [[inheritance|Subclasses]]
`private` : Only accessible within the same class
`default` ( no modifier ) : Only accessible within the same package
