#  Java primitive types :DeJavaOriginal:



These types can be converted to another with [[casting]]

````java title="dataTypes"
byte name = 0; // 8bit integer
short name = 0; // 16bit integer 
int name= 0; // 32bit integer
long name = 0; // 64bit integer
float name = 0F; // 32bit decimal number
double name = 0; // 64bit decimal number (more precise than float)
boolean name = false; // logical value (True or False)
char name = 'a'; // 16 bits unicode char
````
