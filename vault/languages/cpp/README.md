# Introduction
C++ is a [[computer-science/compilers/README|compiled]] language, refered to as a superset of C, which means it shares most of the syntax and building blocks with C (see [[C-diffs|exceptions]]) but extended with objects (see [[OOP]]).

It is strongly recommended to take a look at the C directory for the basics, as that knowledge will be assumed here and only C++ specifics will be covered.
