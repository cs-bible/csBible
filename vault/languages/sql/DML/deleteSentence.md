# :DeMysqlOriginal: Data elimination - Delete Sentence

Deletes any row (selected in the condition with `WHERE`) from the table of the database

## Related Topics
- [[updateSentence|UPDATE]] — modify data instead of deleting
- [[insertSentence|INSERT]] — add data
- [[dropSentence|DROP]] — delete entire tables
## Syntax

```sql title="deleteSentence"
DELETE FROM tableName
[WHERE condition]
[ORDER BY customOrder];
```
