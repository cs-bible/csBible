# Relational operands

```sql  title="SQLrelationalOperands
WHERE age       > 18
WHERE price     < 100
WHERE salary   >= 1500
WHERE quantity <= 20
WHERE name      = 'Jhon'
WHERE role     != 'admin'
WHERE score    !> 80
WHERE ranking  !< 5
```

# Logical operands

```sql title="SQL_logicalOperands" 
WHERE age > 18 AND city = 'Madrid'
WHERE price < 100 OR quantity > 5
WHERE NOT status = 'active'
```
