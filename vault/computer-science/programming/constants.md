#  Constants :LiLocateFixed:

Used for data that never changes, this way we make sure the value is never gonna change.

## Related Topics

## Syntax
```java title="constants" group="constants"
final static double PI = 3.1415;
```
```cpp title="constants" group="constants"
define PI = 3.1415; // starts with a # 
const double PI = 3.1415;
```
```c title="constants" group="constants"
define PI 3.1415;
const double PI 3.1415;
```
```python title="constants" group="constants"
PI = 3.1415;
```
```js title="constants" group="constants"
const double PI = 3.1415;
```
