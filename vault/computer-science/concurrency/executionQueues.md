# Process
> [!note] Process
> A process is a program being executed
# Execution queues
## :LiWorkflow: Fifo - First Input First Output

> [! example] FIFO
> It means that the first instruction / process that comes into line runs first, is a linear execution

## :LiStackHorizontal: Lifo - Last Input First Output - Stack

> [! example]
> It means that the last instruction / process that comes into line runs first, non-linear execution
