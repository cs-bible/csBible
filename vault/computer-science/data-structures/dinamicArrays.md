# Dinamyc Arrays :LiBrackets: :LiPlus:

A dynamic array is a structure that behaves like a normal array but **automatically resizes at runtime**.
It maintains two key properties:
- `size` → number of elements actually stored
- `capacity` → total allocated space

When the array becomes full, it **creates a larger array, copies elements, and continues working transparently**.
