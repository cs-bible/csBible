# 💾 Data Models

# Conceptual Model 
Allows representation of the data that is stored in the database, just like the user visualizes it.
[[entityRelationModel|Entity-Relation Model]] is an example of a conceptual model.

# Logical Model
Less understandable, but with the possibility of being translated directly to the model that the Database Management System understands
- Hierarchical
- Relational Model
- Object Oriented Databases
# Physical Model
Varies for each DMS (Database Management System) but its usually based in SQL (Standard Query Language) language.
